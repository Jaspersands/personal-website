WASM QEC Simulator

Rust → WebAssembly · surface code decoding in the browser

A symplectic stabilizer simulator written in Rust and compiled to WebAssembly, for rotated and XZZX surface codes. It is the engine behind the lattice at the top of this page. An error on a data qubit lights the stabilizers that anticommute with it, and that pattern of lit stabilizers is all a real quantum computer gets to see, because measuring the error directly would collapse the state. Decoding works backwards from the pattern to a likely error; the decoders here, including minimum-weight perfect matching, do it properly and run entirely in the browser, with live error injection and logical error benchmarking.

Threshold · exact MWPM 20k shots/pt

Phenomenological noise, T = d rounds, exact MWPM, measured on the simulator itself. A finite-size scaling fit estimates the threshold at 3.2%: below it a bigger code wins, above it a bigger code just gives noise more places to land. Union-Find on the same sweep thresholds at 2.7%, and code-capacity noise at 14.7%.

Noise-Aware Adiabatic Simulation

IBM Heron r2 · transverse-field Ising model

Digitized adiabatic ground state preparation for the 1D transverse-field Ising model on IBM's Heron r2. I used the processor's parameterised RZZ(θ) pulses rather than fixed two-qubit decompositions, plus a palindromic Trotter step for second-order accuracy. The gap closes near the critical point, so a linear sweep moves too quickly through the part that matters; flattening the schedule around s꜀ slows it down there instead. Benchmarking eight ansatz variants gave the more interesting result. A counterdiabatic correction that is exact in the closed-system limit is a net loss under real noise: its threefold entangling-gate overhead admits more error per layer than the correction removes. The best ansatz on hardware is not the best ansatz on a simulator.

Q-Search

Proof-gated quantum algorithm research & verification engine

An automated research engine investigating structural quantum advantage for hard computational problems (non-abelian HSP, dihedral cosets, and linear code equivalence). Rather than generating toy circuits, the platform pairs frontier theoretical reasoning (GPT) with autonomous agentic engineering (Gemini) to attack proposed quantum mechanisms against 1,200+ classical baselines, enforcing formal proof gates and permanently indexing 800+ negative results across 720+ theorem modules.

Candidate mechanisms for non-abelian HSP, dihedral cosets and linear code equivalence have to clear a formal proof gate and then beat the classical baselines. Failures are not discarded: they are written to a permanent index, which is what stops the engine from re-proposing the same dead end.

Entanglement & Matrix Product States

Many-body systems · theoretical study

A study of how bipartite entanglement structure controls MPS compression. I wrote a sequential SVD wavefunction decomposition in Python and measured Schmidt spectra, entanglement entropy at every cut, and fidelity under truncation. A product state needs bond dimension 1 and a Haar-random state needs exponentially many, so the useful cases fall somewhere between the two.

LLM-Based Lossless Text Compression

Systems optimization

Throughput and memory limits for text compression using autoregressive LLMs with arithmetic coding. Average compression came out between 5× and 16×, with a best case of 39×, which beats both zstd and gzip. Static KV caching, CUDA graph capture, and segment-level batched inference are what made it fast enough to be usable.
